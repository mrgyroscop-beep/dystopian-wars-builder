# Извлечение изображений кораблей из ORBAT

Кампанийные карточки используют отдельные прозрачные WebP из `public/campaign/ships/`.
Они извлекаются из встроенных растровых слоёв PDF, а не вырезаются из скриншота страницы.
Так сохраняются исходная резкость и прозрачный фон без текста, таблиц и бумажной текстуры.

## Где хранится конфигурация

`scripts/campaign/ship-image-sources.json` содержит:

- URL и SHA-256 поддерживаемой версии каждого ORBAT;
- номер страницы (нумерация PDF, начиная с 1);
- индекс встроенного изображения на странице;
- имя кампанийного профиля и выходного WebP.

Индексы слоёв стабильны только для PDF с указанным SHA-256. При обновлении ORBAT страницы и
индексы нужно проверить заново.

## Полное извлечение

Положите исходные PDF по путям, указанным в манифесте, затем выполните:

```powershell
& "C:\Users\user\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" `
  scripts/campaign/extract_ship_images.py `
  --contact-sheet tmp/pdfs/campaign-ship-contact-sheet.jpg
```

Скрипт проверяет хеши PDF, восстанавливает `/SMask`, обрезает прозрачные поля с небольшим
запасом и сохраняет lossless WebP. Контактный лист нужен для обязательной визуальной проверки.

## Добавление нового корабля

1. Найдите страницу профиля в ORBAT.
2. Экспортируйте все встроенные изображения страницы:

   ```powershell
   & "C:\Users\user\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe" `
     scripts/campaign/extract_ship_images.py --inspect crown 31
   ```

3. Откройте контактный лист в `tmp/pdfs/ship-image-inspection/crown-31/contact-sheet.jpg` и
   определите индекс слоя с моделью из правого нижнего угла страницы.
4. Добавьте запись в `ships` файла `ship-image-sources.json`.
5. Добавьте путь в `src/campaign/campaignShipImages.ts`.
6. Запустите полное извлечение и проверьте контактный лист: без фрагментов таблиц, фона,
   обрезанных деталей и посторонних моделей.
7. Проверьте кампанийные карточки на desktop и mobile. Высокие модели (роторы, колоссы,
   автоматоны) должны полностью помещаться в контейнер через `object-fit: contain`.

## Особые случаи

- Некоторые Empire PDF хранят soft-mask как JPEG после цепочки `FlateDecode/DCTDecode`.
  Скрипт декодирует такие маски через Pillow и масштабирует их к размеру цветного слоя.
- Если на странице несколько вариантов модели, выбирайте слой, соответствующий профилю, и
  проверяйте его на полной отрендеренной странице.
- Нельзя подменять специальный кампанийный объект похожей ORBAT-моделью. Поэтому Ashmore
  Refinery остаётся без изображения, пока не появится точный источник.
