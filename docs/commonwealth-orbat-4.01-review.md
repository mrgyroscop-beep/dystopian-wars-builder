## Карточки и изображения

Все прежние 41 соответствие страниц сохранены. Добавлены четыре профиля,
пропущенные из-за разницы названий в оглавлении:

- Jadwiga Airborne Monitor → Jadwiga Aerial Monitor, стр. 41;
- Yak Transport Hovercraft → Yak Hovercraft, стр. 60;
- Europa Grand Conveyor → Europa Grand Conveyer, стр. 61;
- Titan Mass Conveyor → Titan Mass Conveyer, стр. 64.

Итого 45 карточек и 45 прозрачных lossless WebP моделей. Из прежних карточек 40
изменились; Hermes на стр. 62 после рендера остался побайтово прежним.
На всех профильных страницах модель снизу справа находится в слое 7 (индекс с нуля),
кроме Marena на стр. 58: слой 6. Слой 7 у Marena — флаг, поэтому исключение обязательно.
Готовые WebP проверены на контактном листе: текст, таблицы и флаги не захвачены;
базы и опоры миниатюр сохранены. `missing.commonwealth` пуст для сопоставленных страниц.
Отдельная запись каталога Morozko Heavy Cryo Cruiser остаётся без изображения:
стр. 36 описывает этот вариант, но изображает обычный Norilsk. Подмена модели
не выполнялась. Europa сохранена как официальный профиль PDF, хотя в текущем
закреплённом каталоге она не является отдельной записью Unit.

Imperium (9 сопоставленных карточек) и Union (15) оставлены без новых изображений.
Скачанные источники совпадают по SHA-256 с закреплёнными версиями 4.00b/4.00a;
проверены растровые слои всех сопоставленных страниц и примеры полного рендера.
В этих старых макетах отсутствует привычный слой модели снизу справа. Заполнять
пустые записи декоративными слоями нельзя. Для отдельной задачи нужны другие
проверенные источники изображений или новые ORBAT этих фракций.

## Воспроизведение

Скачать новый PDF по ссылке выше и передать его явно, чтобы не затереть пользовательские
файлы в `tmp/` и не использовать старую копию из кеша:

```powershell
python scripts/orbat/publish-cards.py --faction commonwealth --pdf <путь-к-новому-PDF>
python scripts/orbat/extract-model-images.py --faction commonwealth --pdf <путь-к-новому-PDF>
```

Первому скрипту нужен собранный локальный каталог `dist/client/catalog` и Poppler.
Второй проверяет SHA-256 PDF по манифесту карточек перед извлечением.
Оба режима `--faction` сохраняют данные остальных фракций. Сборка через `npm run build`
создаёт локальные файлы; публикация в сеть и деплой не выполнялись.
